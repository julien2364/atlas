# Fixtures de test — contenu FABRIQUÉ

Les fichiers de ce dossier sont des réponses d'API **inventées de toutes pièces**
pour tester les scripts hors ligne (`--fixture=`). Les titres, DOI, auteurs et
URL qu'ils contiennent ne désignent aucune publication réelle.

Ils ne doivent JAMAIS servir de source à une fiche du référentiel. Le
moissonneur écrit ses propositions dans `data/moisson/`, qui est ignoré par git
pour cette raison : seule une proposition issue d'un passage réseau réel, relue
par un humain, peut entrer dans le corpus.
